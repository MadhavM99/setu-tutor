## Failure analysis: abstention on correct sentences

No condition abstained on any of the 29 correct sentences. The top retrieval score on a correct sentence is never below the threshold (0.5): min 0.565, median 1.434, against planted min 0.6, median 1.388, and attacks median 0.295. A correct sentence uses the same words as its wrong version, so it matches the same rule just as strongly: the score measures topic, not error. Abstention can only filter off-topic input; whether a sentence has a mistake must come from the checker before the coach is called.

## Measures

- **hint shown**: a model hint passed every filter and was shown (else the generic hint).
- **shown and usable**: shown, and no reference to the coach's numbered sources (coach.NUMBERED_SOURCE); defined after seeing the run (post-hoc).
- **top-1 retrieved = planted**: the first rule given to the model is the planted rule (retrieval only; oracle: always).
- **model cites planted**: the rule the model names in its `source` field is the planted rule, whether or not the hint was shown.
- **shown hint cites planted**: hint shown AND the model's `source` is the planted rule.

## Notes

- The title-given coach (a') works only for Raju's planted mistakes, where the planted rule is known. For the learner's own sentences there is no planted rule; that is the case retrieval is for.
- 'Shown and usable' = shown AND not referring to the coach's numbered sources (`coach.NUMBERED_SOURCE`, e.g. 'नियम 3'), which the learner never sees. This measure was defined after seeing the run (post-hoc).
- b_fixed_posthoc: condition (b) rerun on the 29 planted cases with a prompt that forbids numbered references and a filter check that rejects them (`coach.SYSTEM_RAG_FIXED`, `coach.numbered_source_check`). The fix was designed after seeing these results, so it is post-hoc; (b) stays the primary result.
- A score threshold separates off-topic input (attacks) from rule-related sentences, but cannot tell a correct sentence from a wrong one: both match the same rule. Deciding correctness is the checker's job.
- 9 of 15 HI->TE explanations are unreviewed drafts; the 10 TE->HI rules have no explanation (title and examples only).
- n = 29 planted cases: intervals are wide; differences of a few cases are not significant.
