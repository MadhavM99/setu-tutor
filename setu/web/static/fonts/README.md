# Self-hosted fonts

Noto Sans Telugu and Noto Sans Devanagari (regular and bold, script subsets only), from the
`@fontsource/noto-sans-telugu@5.3.0` and `@fontsource/noto-sans-devanagari@5.3.0` npm packages
(cdn.jsdelivr.net). Licensed under the SIL Open Font License 1.1 (`OFL-telugu.txt`, `OFL-devanagari.txt`).
Served by the app itself, so no learner request ever goes to a font CDN (E-15). `SHA256SUMS` pins the files.
No Latin subset is shipped: learner-facing text contains no Latin script.
